# pixel-agents-web

Standalone web port of [pixel-agents](https://github.com/pablodelucca/pixel-agents) VS Code extension by Pablo De Lucca (MIT).

Replaces the VS Code Webview API with Express + WebSocket, enabling:

```bash
npx pixel-agents-web --path .
```

No VS Code required.
